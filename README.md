# حسبة برما · Hesbet Barma

A cartoon math-blocks game on notebook paper: arrange the blocks and solve sums with **Professor Owl** (الأستاذ بومة) and **Toto** the hedgehog (توتو), from KG to grade 6. Endless, One-Minute Sprint and Calm Practice modes, a daily challenge with a streak, a shop, 16 trophies and power-ups.
